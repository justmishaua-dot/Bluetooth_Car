# 🚗 Arduino — управление двумя моторами по Serial

## 📌 Описание проекта

Данный проект предназначен для управления **двумя двигателями постоянного тока** с помощью Arduino и моторного драйвера.

Управление осуществляется через **Serial-порт**. Arduino получает однобайтные команды и в зависимости от полученной команды задаёт направление и скорость вращения каждого двигателя.

Поддерживаются четыре основные команды:

| Команда | Действие        |
| ------- | --------------- |
| `F`     | Движение вперёд |
| `B`     | Движение назад  |
| `L`     | Поворот налево  |
| `R`     | Поворот направо |

При получении новой команды двигатели сначала останавливаются, после чего выполняется выбранное действие.

---

## 🔧 Используемое оборудование

Для работы проекта необходимы:

* Arduino с поддержкой `Serial`;
* два двигателя постоянного тока;
* моторный драйвер;
* источник питания двигателей;
* соединительные провода;
* USB-кабель для программирования и передачи команд.

Моторный драйвер должен позволять отдельно управлять направлением вращения и PWM-скоростью каждого двигателя.

---

## ⚡ Настройка скорости

Скорость двигателей задаётся значениями PWM от `0` до `255`:

```cpp
int pwm_speedA = 255;
int pwm_speedB = 240;
```

Где:

* `0` — двигатель выключен;
* `255` — максимальная скорость;
* `pwm_speedA` — скорость двигателя A;
* `pwm_speedB` — скорость двигателя B.

В данном проекте установлено:

```text
Motor A: 255
Motor B: 240
```

Разные значения скорости могут использоваться для компенсации различий между двигателями. Например, если робот немного уходит в сторону при движении прямо, скорость одного двигателя можно уменьшить.

# 🔌 Распиновка

В программе используются следующие выводы Arduino:

|  Pin | Назначение              |
| ---: | ----------------------- |
| `11` | Направление двигателя A |
| `10` | Направление двигателя A |
|  `9` | Направление двигателя B |
|  `6` | Направление двигателя B |
|  `5` | PWM двигателя A         |
|  `3` | PWM двигателя B         |

Настройка выполняется в `setup()`:

```cpp
pinMode(11, OUTPUT);
pinMode(10, OUTPUT);
pinMode(9, OUTPUT);
pinMode(6, OUTPUT);
pinMode(5, OUTPUT);
pinMode(3, OUTPUT);
```

> Точная физическая распиновка моторного драйвера зависит от используемой платы. В данном проекте номера соответствуют именно Arduino-коду.

# 📡 Serial-команды

Serial-порт работает со скоростью:

```cpp
Serial.begin(9600);
```

Поэтому устройство управления должно использовать:

```text
Baud rate: 9600
```

### Команды

```text
F → Forward
B → Backward
L → Left
R → Right
```

Пример:

```text
F
```

Arduino начинает движение вперёд.

---

# ▶️ Движение вперёд

Функция:

```cpp
void forward()
```

устанавливает направления обоих двигателей на движение вперёд и задаёт PWM:

```cpp
analogWrite(5, pwm_speedA);
analogWrite(3, pwm_speedB);
```

То есть:

```text
Motor A → 255
Motor B → 240
```

Схематично:

```text
        ┌───────────────┐
        │    ARDUINO    │
        └───────┬───────┘
                │
          команда F
                │
        ┌───────▼───────┐
        │ MOTOR DRIVER  │
        └───────┬───────┘
             ↙     ↘
          Motor A  Motor B
             →        →
          255 PWM   240 PWM
```

---

# ◀️ Движение назад

Функция:

```cpp
void backward()
```

меняет полярность управления двигателями:

```cpp
digitalWrite(10, LOW);
digitalWrite(11, HIGH);

digitalWrite(9, LOW);
digitalWrite(6, HIGH);
```

Скорость при этом остаётся:

```cpp
Motor A → pwm_speedA
Motor B → pwm_speedB
```

Команда:

```text
B
```

запускает движение назад.

---

# ↩️ Поворот налево

Функция:

```cpp
void left()
```

останавливает двигатель A:

```cpp
analogWrite(3, 0);
```

а двигатель B продолжает работать:

```cpp
analogWrite(5, pwm_speedA);
```

Таким образом робот поворачивает налево за счёт работы только одного двигателя.

Команда:

```text
L
```

---

# ↪️ Поворот направо

Функция:

```cpp
void right()
```

работает аналогично, но отключает другой двигатель:

```cpp
analogWrite(5, 0);
```

и оставляет работающим двигатель B:

```cpp
analogWrite(3, pwm_speedB);
```

Команда:

```text
R
```

---

# 🛑 Остановка

Функция:

```cpp
void motors_stop()
```

полностью отключает оба двигателя:

```cpp
analogWrite(5, 0);
analogWrite(3, 0);
```

а управляющие выводы устанавливаются в `LOW`.

Особенность программы заключается в том, что перед обработкой **каждой новой команды** сначала вызывается:

```cpp
motors_stop();
```

Поэтому последовательность выглядит так:

```text
Получена команда
      ↓
Остановить моторы
      ↓
Определить команду
      ↓
Запустить нужный режим
```

Это снижает вероятность того, что предыдущий режим управления останется активным.

# 🔄 Основной цикл программы

Главная логика находится в:

```cpp
void loop()
```

Arduino постоянно проверяет наличие данных:

```cpp
if(Serial.available() > 0)
```

Если команда получена:

```cpp
command = Serial.read();
```

после чего используется `switch`:

```cpp
switch(command){

  case 'F':
    forward();
    break;

  case 'B':
    backward();
    break;

  case 'L':
    left();
    break;

  case 'R':
    right();
    break;
}
```

Получается простая система управления:

```text
              Serial
                │
                ▼
        ┌───────────────┐
        │ Получить      │
        │ команду       │
        └───────┬───────┘
                │
                ▼
        ┌───────────────┐
        │ motors_stop() │
        └───────┬───────┘
                │
        ┌───────▼────────┐
        │    SWITCH      │
        └─┬───┬───┬───┬──┘
          │   │   │   │
          F   B   L   R
          │   │   │   │
          ▼   ▼   ▼   ▼
         ↗   ↙   ←   →
```

# 🛠️ Настройка скорости

Если робот при движении вперёд уходит в одну сторону, можно изменить:

```cpp
int pwm_speedA = 255;
int pwm_speedB = 240;
```

Например:

```cpp
int pwm_speedA = 230;
int pwm_speedB = 240;
```

или:

```cpp
int pwm_speedA = 250;
int pwm_speedB = 235;
```

Настройку следует выполнять экспериментально.

Диапазон:

```text
0 ─────────────── 255
│                  │
стоп          максимум
```

# ⚠️ Важные замечания

### 1. Питание двигателей

Не следует питать мощные двигатели непосредственно от GPIO Arduino. Выводы Arduino должны управлять **моторным драйвером**, а не подавать ток двигателя напрямую.

### 2. Общая земля

Arduino и моторный драйвер должны иметь общую `GND`, если схема управления требует общего потенциала земли.

### 3. PWM

Используемые выводы:

```text
3
5
```

используются для управления скоростью через:

```cpp
analogWrite()
```

### 4. Нулевая команда

Любой символ, кроме:

```text
F
B
L
R
```

не запускает движение. Однако перед обработкой команды моторы уже будут остановлены.
